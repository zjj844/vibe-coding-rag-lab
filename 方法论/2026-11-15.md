## 今天用了什么 Prompt
1. **"帮我理解这个项目，告诉我先从哪里入手去了解，我是一个0基础vibe coding学者"** + GitHub 链接

## 纠错复盘
- **git push 报错 `could not read Username for 'https://github.com'`**
  - 排查过程：推送失败 → 读报错 → 确认不是网络/仓库地址问题，而是缺少身份凭据
  - 原因：GitHub 已不接受密码推送，HTTPS 推送需通过 Git Credential Manager 完成一次浏览器授权；后台非交互环境弹不出授权窗口
  - 解决：在本地终端手动执行 push，让授权窗口弹出（一次性操作，之后凭据会被缓存）
  - 最佳实践沉淀：**遇到"要用户名/密码"类报错，先想"它需要交互式授权"，换个能弹窗的环境做，而不是反复重试同一命令**

## 概念积累
- **JD**：岗位描述（招聘要求的原文）
- **Prompt**：发给 AI 的指令文本，AI 编程协作的"源代码"
- **RAG**：让大模型先查资料再回答（开卷考试）；两阶段 = 检索 + 生成
- **GitHub 仓库**：项目的云端文件夹，与本地文件夹同步

## 一句最佳实践
> 让 AI 做规划时，给它"截止日期 + 自己的真实水平 + 相关材料全文"，三者缺一则计划不可执行。
