# 接口 401 认证失败排查

现象：脚本调用模型接口，返回 401 Unauthorized。

第一次误判：以为密钥过期，去后台重新生成了一把。

真实原因：base_url 指向了第三方聚合网关 AIHubmix，但填进去的却是 DeepSeek 官方的密钥。网关不认识这个密钥，于是返回 401。

教训：401 有两层含义——密钥无效，或者密钥与接口地址不匹配。先核对 base_url 和 key 是否来自同一个平台。

排查顺序：打印实际请求的 base_url；确认环境变量读取成功，值不为空且没有多余空格和引号；用 curl 打一个最小请求；最后才检查客户端代码。

另外两个高频错误：把 Python 代码粘进终端执行、缩进错误导致 IndentationError。这两种都不是认证问题，但常常和 401 一起出现，容易混淆。
